# 📊 Sales Performance & Customer Insights Dashboard

An end-to-end Data Analytics project built using **MySQL** and **Power BI** to analyze sales performance, customer behavior, product profitability, and regional business insights using the Global Superstore dataset.

---

# 🚀 Project Overview

This project focuses on transforming raw retail sales data into meaningful business insights through:

- Data Cleaning & Validation
- SQL-based Data Analysis
- KPI Tracking
- Interactive Power BI Dashboards
- Customer & Product Performance Analysis
- Regional & Operational Insights

The goal of this project was to simulate a real-world business intelligence workflow followed by Data Analysts.

# 📂 Project Workflow

## 1️⃣ Data Collection
- Imported Global Superstore dataset into MySQL
- Handled CSV import issues and datatype mismatches

## 2️⃣ Data Cleaning
Performed:
- NULL value checks
- Duplicate analysis
- Date formatting corrections
- Data validation
- Consistency checks

## 3️⃣ SQL Analysis
Built SQL queries for:
- Monthly sales trends
- Top-performing products
- Loss-making products
- Customer revenue analysis
- Category profitability
- Regional sales analysis
- Market-wise performance
- Shipping mode insights

## 4️⃣ Dashboard Development
Designed interactive multi-page Power BI dashboards to visualize:
- Sales KPIs
- Product insights
- Customer behavior
- Regional performance
- Operational trends

---

🔍 Key Business Insights

✅ Consumer segment generated the highest revenue contribution.

✅ APAC and US markets showed strong sales performance.

✅ Standard Class shipping mode dominated total orders.

✅ Several high-selling products were identified as loss-making products.

✅ Technology category contributed the highest overall profit.
